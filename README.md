# 我的主页 · 0.1.0

一个独立的 Obsidian 个人主页插件。代码自行编写，参考模块化组织思路，不依赖万象，不包含授权、广告、联网服务或外部包安装步骤。

## 安装

1. 在你的 Obsidian 仓库中打开 `.obsidian/plugins/`（如果更改过配置目录，请使用对应目录）。
2. 将整个 `my-homepage` 文件夹放进去。必须保留 `core/` 与 `modules/`，不能只复制三个入口文件。
3. 在 Obsidian 中打开“设置 → 第三方插件”，关闭受限模式后启用“我的主页”。如未出现，请重新加载 Obsidian。
4. 点击左侧房子图标，或在命令面板搜索“我的主页：打开主页”。

## 使用与设置

主页右上角“设置主页”会打开独立设置页，也可从 Obsidian 插件设置进入。支持标题、介绍、主题色、启动打开、列数、模块显隐和上下排序。

快捷入口每行填写 `名称 | 文件夹/笔记.md`，点击保存后生效。路径相对当前仓库根目录；只打开已有 Markdown 笔记，不会自动创建文件。

默认四个模块：日期与时钟、快捷入口、今日待办、最近笔记。待办是持续保留的独立列表，不是每日自动归档的日计划，也不会读取或修改笔记任务。最近笔记按文件修改时间排列。

也可以在笔记中嵌入完整主页：

````markdown
```my-homepage
```
````

代码块目前不接受参数，使用全局设置。适用于阅读视图与 Live Preview，源码模式只显示原始文本。

## 数据与限制

- 设置与待办保存在插件目录的 `data.json`，为明文。备份时保留这个文件；更新代码时不要覆盖它。
- 保存失败会通知并记录控制台错误；写入按顺序执行。此版本没有多设备冲突合并，仓库同步是否包含插件目录取决于同步工具配置。
- 多个已打开的主页共享数据，待办修改会刷新其他主页实例。
- 主题使用宿主颜色变量，窄分栏或手机自动单列；移动端和不同主题仍需实际验证。
- 插件不主动联网。
- 当前验证包括 JavaScript 语法、设置恢复、路径解析和保存顺序测试；尚未在真实 Obsidian 内进行界面验收。

## 源码结构

```text
main.js             插件入口、主页视图、代码块、设置页、保存队列
core/model.js       默认值、数据规范化、快捷入口解析
modules/index.js    四个模块的渲染与资源清理
styles.css          主题与响应式样式
manifest.json       插件身份
tests/              使用 Node 内置测试工具验证核心行为
```

不需要构建。开发验证：`node --test tests/*.test.js`。添加模块时，在 `core/model.js` 的 IDS 与默认 visible 中添加 ID，再在 `modules/index.js` 添加 `{ id, name, render }`；设置页自动列出模块。模块创建计时器或事件监听时必须使用 `cleanup()` 登记释放方法。
